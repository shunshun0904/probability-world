# 確率の世界 — Probability World

**確率を、見て・動かして・発見する。**

身近な現象を何度もシミュレーションし、実測のヒストグラムと理論的な確率分布を見比べる、日本語のブラウザ学習サイトです。

**公開サイト：** https://shunshun0904.github.io/probability-world/

## 学べる実験

| 現象 | 確率モデル |
| --- | --- |
| コイン投げの表の回数 | ベルヌーイ試行・二項分布 |
| 小さな独立な測定誤差の合計 | 正規分布への近似・中心極限定理 |
| 1回の営業で来たお客さんの人数 | ポアソン過程・ポアソン分布 |
| 次の来客までの時間 | 指数分布 |
| 大きな損失の発生 | 対数正規分布・パレート分布 |
| サイコロを何度も振る | 大数の法則 |

実験ごとにパラメータ操作、自動再生、実測と理論の比較、累積分布、平均・分散、予測クイズを用意しています。各シミュレーションは**特定の仮定を置いたモデル**であり、実際の現象がその分布に必ず従うことを意味しません。

## Shorts Studio — ショート動画の生成

https://shunshun0904.github.io/probability-world/?studio=arrivals

1. 5つの実験から題材を選ぶか、各実験ページから「動画を生成」を開きます。
2. 来客率・コインの成功確率・誤差の個数などの条件を選びます。
3. **15秒または30秒**を選び、9:16の動画をプレビューします。
4. **「縦型動画を生成する」**を押して、ブラウザで録画します。
5. 完成した動画をダウンロードし、必要に応じてナレーション・BGMを加えます。台本テキストも保存できます。

- 出力サイズ：720 × 1280（縦型 9:16）、24 fps。
- 出力形式：ブラウザが対応する場合はMP4、そうでない場合はWebM。最終的な形式は画面に表示されます。
- 出力音声：なし（字幕・図解付き）。YouTubeへの自動投稿は行いません。
- 生成処理は**ブラウザ内**で実行されます。録画中はタブを開いて表示したままにしてください。
- シード付き疑似乱数で再現性を確保。共有URLには対象の実験・条件・シードを含めます。
- 録画機能はブラウザのMediaRecorder / Canvas captureStream対応状況に依存します。

## 開発

Node.js 22以降を使用します。

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

React + TypeScript + Vite。GitHub Actionsでテスト・ビルドを検証し、`main`への更新をGitHub Pagesにデプロイします。

## ディレクトリ構成

- `src/App.tsx`：トップページ、分布探索、ページルーティング
- `src/PhenomenaLab.tsx` / `src/simulations.ts`：現象ベースの実験と確率モデル
- `src/ShortsStudio.tsx`：動画作成UI
- `src/shortsEngine.ts`：台本と9:16のフレーム描画
- `src/shortsRecorder.ts`：録画・WebM/MP4形式での書き出し
- `src/shortsRoutes.ts`：実験条件とシードのURL共有

今後は、分布図鑑の充実、確率モデル間の比較、動画ナレーション・編集機能などを拡張する予定です。
